# Шпора: все формулы

Структура: (1) блок самых частых — дублируются в основной части; (2) базовые «как считается что»; (3) основная часть в хронологическом порядке тем.
Подробности по каждому распределению — в `raspredeleniya.md`.

---

## 1. Самые частые формулы

| Формула | Что даёт |
|---|---|
| $P(\overline{A}) = 1 - P(A)$ | «хотя бы один» через «ни одного» |
| $P(A \cup B) = P(A) + P(B) - P(AB)$ | объединение совместных |
| $P(A \mid B) = \dfrac{P(AB)}{P(B)}$ | условная вероятность |
| $P(A) = \sum_i P(A \mid H_i) P(H_i)$ | полная вероятность |
| $P(H_i \mid A) = \dfrac{P(A \mid H_i) P(H_i)}{P(A)}$ | Байес |
| $E(aX + bY) = a\,EX + b\,EY$ | линейность $E$ — всегда |
| $D(aX + b) = a^2 DX$ | масштаб/сдвиг |
| $D(X + Y) = DX + DY + 2\,\mathrm{Cov}(X, Y)$ | сумма (при независимых $+2\mathrm{Cov}$ исчезает) |
| $\mathrm{Cov}(X, Y) = E[XY] - EX \cdot EY$ | ковариация через моменты |
| $\rho(X, Y) = \dfrac{\mathrm{Cov}(X, Y)}{\sigma_X \sigma_Y} \in [-1, 1]$ | корреляция |
| $A_n^k = \dfrac{n!}{(n-k)!}$, $C_n^k = \dfrac{n!}{k!\,(n-k)!}$ | размещения/сочетания |

## 2. Базовые: как что считается

### Матожидание $E$
- Дискретная СВ: $EX = \sum_i x_i\, p_i$.
- Непрерывная СВ: $EX = \int_{-\infty}^{\infty} x\, f(x)\, dx$.
- Функция от СВ: $E[g(X)] = \sum g(x_i) p_i$ или $\int g(x) f(x)\, dx$ (без пересчёта распределения $g(X)$).
- Линейность — **всегда**: $E(aX + bY + c) = aEX + bEY + c$, даже для зависимых.
- $E[XY] = EX \cdot EY$ — **только** для независимых (достаточно некоррелированности — нет, это одно и то же для произведения: равенство ⇔ $\mathrm{Cov} = 0$; но $Cov = 0$ ⇏ независимость).

### Дисперсия $D$
- Определение: $DX = E(X - EX)^2$.
- Рабочая формула: $DX = EX^2 - (EX)^2$ (считать так обычно проще).
- Сдвиг/масштаб: $D(aX + b) = a^2 DX$ (константа $b$ разброс не меняет).
- Сумма — общий случай: $D(X + Y) = DX + DY + 2\,\mathrm{Cov}(X, Y)$.
- Сумма — независимые (или $\mathrm{Cov} = 0$): $D(X + Y) = DX + DY$.
- $D(cX) = c^2 DX$; СКО $= \sqrt{DX}$ — в единицах $X$.

### Ковариация $\mathrm{Cov}$ и корреляция $\rho$
- Определение: $\mathrm{Cov}(X, Y) = E(X - EX)(Y - EY)$.
- Рабочая формула: $\mathrm{Cov}(X, Y) = E[XY] - EX \cdot EY$.
- Билинейность: $\mathrm{Cov}(aX + bY, Z) = a\,\mathrm{Cov}(X, Z) + b\,\mathrm{Cov}(Y, Z)$; $\mathrm{Cov}(X, X) = DX$.
- Независимость ⟹ $\mathrm{Cov}(X, Y) = 0$. Обратно — **нет** ($\rho = 0$ ≠ независимость; исключение — jointly normal).
- Границы: $|\mathrm{Cov}(X, Y)| \le \sigma_X \sigma_Y$; $\rho \in [-1, 1]$; $\rho = \pm 1$ ⟺ линейная связь $Y = aX + b$ ($a \gtrless 0$).

## 3. Основная часть: хронологический порядок (по темам)

### Тема 1: комбинаторика и основы
- Правило умножения: $k$ шагов с $n_i$ вариантами → $\prod n_i$.
- Перестановки: $n!$. Перестановки с повторениями: $\dfrac{n!}{k_1!\cdots k_r!}$.
- Размещения (порядок важен, без повторов): $A_n^k = \dfrac{n!}{(n-k)!}$.
- Сочетания (порядок не важен): $C_n^k = \dfrac{n!}{k!(n-k)!}$.
- Классическая вероятность: $P(A) = \dfrac{|A|}{|\Omega|}$ (исходы равновозможны).
- Свойства: $P(\emptyset) = 0$; $P(\overline{A}) = 1 - P(A)$; $A \subseteq B \Rightarrow P(A) \le P(B)$; $P(A \cup B) = P(A) + P(B) - P(AB)$; субаддитивность $P(\bigcup A_i) \le \sum P(A_i)$.
- Включения-исключения: $P(\bigcup_{i=1}^n A_i) = \sum_i P(A_i) - \sum_{i<j} P(A_iA_j) + \dots + (-1)^{n-1} P(A_1 \dots A_n)$.
- Геометрическая вероятность: $P(A) = \dfrac{\text{мера}(A)}{\text{мера}(\Omega)}$ (длина/площадь).

### Тема 2: условная вероятность и Байес
- Условная вероятность: $P(A \mid B) = \dfrac{P(AB)}{P(B)}$, $P(B) > 0$.
- Независимость: $P(AB) = P(A)P(B)$ ⟺ $P(A \mid B) = P(A)$.
- Полная вероятность (гипотезы $H_i$ — полная несовместная группа): $P(A) = \sum_i P(A \mid H_i) P(H_i)$.
- Байес: $P(H_i \mid A) = \dfrac{P(A \mid H_i)\, P(H_i)}{\sum_j P(A \mid H_j) P(H_j)}$.

### Тема 3: дискретные СВ ⏳
- $F(x) = P(X \le x)$; $P(a < X \le b) = F(b) - F(a)$; $P(X = x_i) = F(x_i) - F(x_i - 0)$.
- $EX = \sum x_i p_i$, $DX = EX^2 - (EX)^2$ (см. блок 2).
- Типовые дискретные (закон, $E$, $D$) — `raspredeleniya.md`.

### Тема 4: непрерывные СВ ⏳
- Плотность: $f(x) = F'(x)$, $\int f = 1$; $P(a \le X \le b) = \int_a^b f(x)\,dx$; $P(X = c) = 0$.
- $EX = \int x f\,dx$; $DX = \int (x - EX)^2 f\,dx$.
- Квантиль уровня $q$: $F(x_q) = q$.

### Тема 5: системы СВ ⏳
- Совместные: $F(x, y)$, для дискретных $p_{ij} = P(X = x_i, Y = y_j)$, для непрерывных $f(x, y)$.
- Маргиналы: суммирование/интегрирование по лишней переменной.
- Независимость: совместное = произведение маргинальных.
- $\mathrm{Cov}(X, Y) = E[XY] - EX \cdot EY$; $D(X \pm Y) = DX + DY \pm 2\mathrm{Cov}(X, Y)$.
- Корреляция и её свойства — блок 2.

### Тема 6: условные распределения и корреляция ⏳
- Заполню по мере прохождения (условные плотности, $E[Y \mid X]$).

### Темы 7–8: наивный Байес
- Классификация: $\hat{y} = \arg\max_y \; P(y) \prod_j P(x_j \mid y)$ (наивная независимость признаков).
- Сглаживание: $P(x_j \mid y) = \dfrac{n_{jy} + \alpha}{n_y + \alpha m}$, $\alpha > 0$ — псевдосчёты (Дирихле).

### Тема 9: распределения в ML ⏳
- Байесовский вывод: апостериор $\propto$ правдоподобие × априор.
- Модель бета-бернулли: апостериор $\mathrm{Beta}(\alpha + k,\ \beta + n - k)$; $E_{\text{post}} = \dfrac{\alpha + k}{\alpha + \beta + n}$; MAP $= \dfrac{\alpha + k - 1}{\alpha + \beta + n - 2}$.
- $P(\mathrm{CTR}_A > \mathrm{CTR}_B) = \int_0^1 f_{\mathrm{Beta}_A}(p)\, F_{\mathrm{Beta}_B}(p)\, dp$ (или Монте-Карло).

### Тема 10: Дирихле ⏳
- Апостериор Дирихле-мультиномиального: $\mathrm{Dir}(\boldsymbol\alpha + \mathbf{k})$.
- $E\theta_i = \alpha_i/\alpha_0$; мода $\theta_i = \dfrac{\alpha_i - 1}{\alpha_0 - m}$ (при $\alpha_i > 1$); маргинал $\mathrm{Beta}(\alpha_i, \alpha_0 - \alpha_i)$.

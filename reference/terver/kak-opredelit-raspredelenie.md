# Шпора: как определить распределение

Алгоритм-детектор: задаёшь себе вопросы по порядку. Детали по каждой модели — в `raspredeleniya.md`.

---

## Шаг 0. Что за величина?

- **Считаем количество** (целое: 0, 1, 2, …) → дискретные.
- **Измеряем время/величину** (неотрицательная непрерывная) → экспоненциальное, гамма.
- **Доля или вероятность** (в $[0, 1]$) → бета; **вектор долей, дающий 1 в сумме** → Дирихле.
- **Отклонение/измерение с ошибкой** (может быть любым числом) → нормальное.

## Шаг 1. Дискретная величина — какой сценарий?

| Вопрос себе | Если «да» | Распределение |
|---|---|---|
| Одно испытание, два исхода? | да | Бернулли$(p)$ |
| Фиксировано число испытаний $n$, считаем успехи? | да | биномиальное$(n,p)$ |
| Испытания проводим **до первого успеха**? | да | геометрическое$(p)$ |
| Выборка **без возвращения** из конечной совокупности? | да | гипергеометрическое$(N, K, n)$ |
| Несколько категорий, $n$ испытаний, считаем счёт по каждой? | да | мультиномиальное |
| Считаем события «за час / на страницу», известна средняя интенсивность $\lambda$? | да | Пуассона$(\lambda)$ |
| Всё равновозможно? | да | дискретное равномерное |

**Проверочные вопросы для биномиального/гипергеометрического:** испытания независимы (с возвращением / совокупность огромна) → биномиальное; вытаскиваем сразу пачку без возврата → гипергеометрическое.

## Шаг 2. Непрерывная величина — какой сценарий?

| Вопрос себе | Если «да» | Распределение |
|---|---|---|
| Время **до первого** события потока? | да | экспоненциальное$(\lambda)$ |
| Время **до $k$-го** события (сумма $k$ времён)? | да | гамма$(k, 1/\lambda)$ |
| Сумма многих независимых случайных вкладов / заданы среднее и разброс? | да | нормальное$(\mu, \sigma^2)$ |
| Речь о вероятности успеха/доле, есть «успехи и неудачи» в данных? | да | бета$(\alpha+k, \beta+n-k)$ |
| Вектор вероятностей категорий, $\sum = 1$? | да | Дирихле$(\boldsymbol\alpha + \mathbf{k})$ |
| Все значения в интервале равновозможны? | да | равномерное на $[a,b]$ |

## Шаг 3. Байесовский контекст (темы 7–10)

Если в задаче есть «неизвестный параметр + данные + априор»:

1. Параметр — вероятность успеха $p \in [0,1]$, данные — «$k$ из $n$» → модель бета-бернулли: апостериор $\mathrm{Beta}(\alpha+k, \beta+n-k)$.
2. Параметр — вектор категориальных вероятностей, данные — счёты $\mathbf{k}$ → модель Дирихле-мультиномиальное: апостериор $\mathrm{Dir}(\boldsymbol\alpha + \mathbf{k})$.
3. Спрашивают «наиболее вероятное значение параметра» → мода апостериора (MAP): у беты $\frac{\alpha+k-1}{\alpha+\beta+n-2}$ (при $\alpha+k>1, \beta+n-k>1$), среднее — $\frac{\alpha+k}{\alpha+\beta+n}$.
4. Сравнение двух вариантов A/B: $P(\mathrm{CTR}_A > \mathrm{CTR}_B)$ — интеграл $\int f_{\mathrm{Beta}_A}(p) F_{\mathrm{Beta}_B}(p)\,dp$ или Монте-Карло.

## Таблица «ключевое слово → распределение»

| Слово/фраза в условии | Кандидат |
|---|---|
| «хотя бы один…» | считать через $1 - P(\text{ни одного})$; за $n$ испытаний — биномиальное |
| «до первого успеха/попадания» | геометрическое (или экспоненциальное — если время) |
| «к раз из n испытаний», «число попаданий» | биномиальное |
| «выбирают пачку без возвращения», «среди отобранных» | гипергеометрическое |
| «за час поступает в среднем 3 звонка», «редкие события» | Пуассона |
| «время до отказа», «время между звонками» | экспоненциальное |
| «время до 5-го отказа» | гамма |
| «погрешность измерения», «сумма множества факторов» | нормальное |
| «вероятность клика неизвестна», «доля брака», CTR | бета (в байесовском контексте) |
| «веса тем в документе», «смесь, дающая 1 в сумме» | Дирихле |

## Подводные камни

1. **Биномиальное vs гипергеометрическое.** Ключ — возвращение: тасуем колоду и вытягиваем 5 карт (без возврата) → гипергеометрическое; 5 раз подбрасываем монету → биномиальное.
2. **Пуассон vs биномиальное.** Большое $n$, маленькое $p$, интересует только среднее $np = \lambda$ → Пуассон; есть фиксированное маленькое $n$ и явное $p$ → биномиальное.
3. **Нумерация геометрического.** «Номер первого успеха» → $E = 1/p$; «число неудач до первого успеха» → $E = (1-p)/p$. Уточни у себя, с чего начинается счёт.
4. **Экспоненциальное: λ или θ?** $\lambda$ — интенсивность (сколько событий в единицу времени), тогда среднее $= 1/\lambda$. Если в условии дано «среднее время 10 минут», то $\lambda = 0{,}1$.
5. **Независимость ≠ некоррелированность.** $\rho = 0$ не гарантирует независимость (кроме jointly normal).
6. **Бета(1,1) — не «нет знаний», а равномерное.** Отсутствие знаний в пропорциях часто кодируют $\alpha = \beta = 1$; но $(0,0)$-предел — « Jeffrey-приор», $(0.5, 0.5)$ — дуга синуса. Следи, какую форму априора просят.
7. **Симплекс Дирихле.** Плотность живёт на треугольнике $\sum\theta_i = 1$; нельзя рисовать «независимые $\theta_i$» — они связаны суммой.

## Тема 1–2: основы и Байес 🟢

**Пространство элементарных исходов $\Omega$** — множество всех взаимоисключающих результатов эксперимента. На пальцах: «список всех вариантов, что может случиться».

**Элементарный исход $\omega$** — один неразложимый вариант результата.

**Событие $A$** — подмножество $\Omega$; произошло ⟺ реализовался один из его исходов.

**Алгебра / σ-алгебра $\mathcal{F}$** — класс событий, замкнутый относительно дополнений и (соотв.) конечных / счётных объединений. На пальцах: «какие множествам разрешено называть событиями».

**Вероятностная мера $P$** — функция на событиях: $P(A) \ge 0$, счётно-аддитивна на непересекающихся, $P(\Omega) = 1$.

**Вероятностное пространство** — тройка $\langle \Omega, \mathcal{F}, P \rangle$. На пальцах: «экспиримент, формализованный до предела».

**Несовместные события** — $A \cap B = \emptyset$: не могут случиться вместе.

**Противоположное событие $\overline{A}$** — «$A$ не случилось»; $P(\overline{A}) = 1 - P(A)$.

**Условная вероятность** $P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}$ — переоценка шансов $A$ после того, как $B$ случилось. На пальцах: «сузили мир до $B$».

**Независимость** — $P(A \cap B) = P(A)P(B)$ (эквивалентно $P(A \mid B) = P(A)$): знание $B$ не меняет шансы $A$.

**Формула полной вероятности** — для полной группы несовместных гипотез $H_i$:
$$P(A) = \sum_i P(A \mid H_i) P(H_i).$$

**Формула Байеса** — переоценка гипотез по наблюдению:
$$P(H_i \mid A) = \frac{P(A \mid H_i) P(H_i)}{P(A)}.$$
На пальцах: «насколько гипотеза объясняет данные × насколько она была вероятна заранее, нормированное».

**Формула включения-исключения** — $P(\bigcup A_i)$ через суммы пересечений с чередующимися знаками.

## Темы 3–6: случайные величины ⏳

**Случайная величина (СВ)** — измеримый результат эксперимента в числах: функция $X: \Omega \to \mathbb{R}$.

**Дискретная / непрерывная СВ** — принимает счётное множество значений / любое значение в континууме.

**Функция распределения (CDF)** $F(x) = P(X \le x)$ — неубывающая, от $0$ до $1$.

**Плотность (PDF)** $f(x) = F'(x)$ — у непрерывных СВ; $P(a \le X \le b) = \int_a^b f$; «вероятность точки» равна $0$, плотность — не вероятность.

**Математическое ожидание $E X$** — «среднее по распределению»: $\sum x_i p_i$ или $\int x f(x)\,dx$. Свойство: $E(aX + bY) = aEX + bEY$ (всегда).

**Дисперсия $D X$** — $E(X - EX)^2 = EX^2 - (EX)^2$ — «разброс вокруг среднего». Свойство: $D(aX+b) = a^2 D X$; для независимых: $D(X+Y) = DX + DY$.

**СКО (σ)** — $\sqrt{D X}$ — разброс в тех же единицах, что $X$.

**Мода / медиана / квантиль** — самая вероятная точка / $F(m) = \frac12$ / точка уровня $q$: $F(x_q) = q$.

**Ковариация** $\mathrm{Cov}(X,Y) = E(X-EX)(Y-EY) = E[XY] - EX\,EY$ — линейная совместная изменчивость.

**Корреляция** $\rho = \dfrac{Cov(X,Y)}{\sqrt{\mathrm{D}X\;\mathrm{D}Y}} \in [-1, 1]$ — нормированная ковариация. На пальцах: «насколько знание $X$ позволяет линейно предсказывать $Y$»; $\rho = 0$ ≠ независимость (кроме нормального случая).

**Условное распределение** — распределение $Y$ при условии $X = x$; у дискретных $P(Y = y \mid X = x)$, у непрерывных — через условную плотность $f_{Y \mid X}(y \mid x)$.

## Темы 7–10: байесовский вывод и ML ⏳

**Правдоподобие $L(\theta) = P(\text{данные} \mid \theta)$** — вероятность данных при фиксированном параметре; как функция от $\theta$ — «насколько данные одобряют $\theta$».

**Априорное распределение** $p(\theta)$ — наши знания о параметре до данных.

**Апостериорное распределение** $p(\theta \mid \text{данные}) \propto p(\text{данные} \mid \theta)\, p(\theta)$ — обновлённые знания. На пальцах: «апостериор = правдоподобие × априор, отнормированное».

**Сопряжённый априор** — априор, при котором апостериор из того же семейства: бета ↔ Бернулли/биномиальное, Дирихле ↔ мультиномиальное, гамма ↔ Пуассон, нормальное ↔ нормальное.

**Псевдосчёты** — интерпретация параметров сопряжённого априора как «наблюдений, которых не было»: $\mathrm{Beta}(1,1)$ = «пустой опыт», апостериорное среднее $\frac{\alpha+k}{\alpha+\beta+n}$.

**MAP-оценка** — мода апостериорного распределения: «наиболее вероятное значение параметра с учётом данных».

**Наивный байесовский классификатор** — классификация по максимуму апостериорной вероятности класса при «наивном» предположении о независимости признаков внутри класса:
$$P(y \mid \mathbf{x}) \propto P(y) \prod_j P(x_j \mid y).$$

**Сглаживание (Лапласа / Дирихле)** — добавление псевдосчётов, чтобы нулевые частоты не обнуляли всё произведение: $P(x_j \mid y) = \frac{n_{jy} + \alpha}{n_y + \alpha m}$.

**Гиперпараметры** — параметры априорного распределения ($\alpha, \beta$ у беты, $\boldsymbol\alpha$ у Дирихле); задаются до данных.

**Гипергеометрическое распределение / точный тест Фишера** — точная модель таблицы $2 \times 2$ при фиксированных краевых суммах (см. шпору распределений).

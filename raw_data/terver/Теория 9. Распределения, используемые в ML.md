# Теория вероятностей

Дата: 

### Напоминание: четыре дискретных распределения

Генеалогическое дерево дискретных распределений: Бернулли (1 испытание, 2 исхода) → Биномиальное ($n$ испытаний, 2 исхода); Категориальное (1 испытание, $K$ исходов) → Мультиномиальное ($n$ испытаний, $K$ исходов). Две оси: число испытаний (1 или $n$) и число исходов (2 или $K$).

| | Параметры | Значения | Вероятность |
|---|---|---|---|
| Бернулли | $p$ | $0,1$ | $p^k(1-p)^{1-k}$ |
| Биномиальное | $n,p$ | $0,\dots,n$ | $C_n^k p^k(1-p)^{n-k}$ |
| Категориальное | $p_1,\dots,p_K$ | $1,\dots,K$ | $p_k$ |
| Мультиномиальное | $n, p_1,\dots,p_K$ | $(x_1,\dots,x_K)$ | $\dfrac{n!}{x_1!\cdots x_K!}\prod_k p_k^{x_k}$ |

Во всех случаях параметры ($p$ или $p_k$) считаются **известными**.

### Проблема: вероятность успеха неизвестна

Хотим **байесовски** оценить $p \in (0,1)$:
1. задать **априорное** распределение на $p$;
2. обновить его по данным;
3. получить **апостериорное** распределение.

Для распределения на $(0,1)$ удобно использовать бета-распределение; для его изучения понадобятся гамма- и бета-функции.

### Гамма-функция

**Определение.**
$$\Gamma(z) = \int_0^\infty t^{z-1} e^{-t}\, dt, \qquad z > 0.$$

Свойства:
- $\Gamma(z+1) = z\,\Gamma(z)$;
- $\Gamma(n) = (n-1)!$ для целых $n \ge 1$;
- $\Gamma(1) = 1$;
- $\Gamma(1/2) = \sqrt{\pi}$.

**Смысл:** обобщение факториала на нецелые аргументы.

При выводе $\Gamma(1/2) = \sqrt{\pi}$ используется интеграл Пуассона:
$$\int_{-\infty}^{\infty} e^{-x^2/2}\, dx = \sqrt{2\pi}, \qquad \int_0^\infty e^{-x^2/2}\, dx = \frac{\sqrt{2\pi}}{2} = \sqrt{\frac{\pi}{2}}.$$

### Бета-функция

**Определение.**
$$B(a,b) = \int_0^1 t^{a-1}(1-t)^{b-1}\, dt, \qquad a, b > 0.$$

Связь с гамма-функцией:
$$B(a,b) = \frac{\Gamma(a)\,\Gamma(b)}{\Gamma(a+b)}.$$

Свойства:
- симметрия: $B(a,b) = B(b,a)$;
- $B(1,1) = 1$;
- $B(2,1) = 1/2$.

**Смысл:** нормировочная константа бета-распределения.

### Бета-распределение

Случайная величина $X$ имеет бета-распределение с параметрами $a, b > 0$, если её плотность

$$f_X(x) = \frac{1}{B(a,b)}\, x^{a-1}(1-x)^{b-1}, \qquad x \in (0,1).$$

Обозначение: $X \sim \mathrm{Beta}(a,b)$.

Носитель — $(0,1)$: естественен для вероятностей.

Параметры:
- $a$ — «форма» слева (тяжесть у $0$);
- $b$ — «форма» справа (тяжесть у $1$).

### Бета-распределение: форма при разных параметрах

| Параметры | Форма |
|---|---|
| $a = b = 1$ | равномерное на $(0,1)$ |
| $a, b > 1$ | колокол |
| $a = b$ | симметричное относительно $1/2$ |
| $a, b < 1$ | U-образное (масса у краёв) |
| $a \gg b$ | масса ближе к $1$ |
| $a \ll b$ | масса ближе к $0$ |

### Бета-распределение: числовые характеристики

Математическое ожидание:
$$\mathsf{E}X = \frac{a}{a+b}.$$

Дисперсия:
$$\mathsf{D}X = \frac{ab}{(a+b)^2 (a+b+1)}.$$

Мода (при $a, b > 1$):
$$\operatorname{mode}(X) = \frac{a-1}{a+b-2}.$$

*Проверка:* при $a = b = 1$ получаем $\mathsf{E}X = 1/2$, $\mathsf{D}X = 1/12$ — равномерное.

### Почему именно бета?

Три аргумента в пользу бета-распределения как модели вероятности:

1. **Носитель.** Вероятность живёт на $(0,1)$, и бета тоже определена на $(0,1)$. Никакого «лишнего» пространства.
2. **Гибкость формы.** Два параметра $a, b$ позволяют получить:
   - равномерное $(a = b = 1)$;
   - колокол $(a, b > 1)$;
   - U-образное $(a, b < 1)$;
   - любую асимметрию $(a \neq b)$.
3. **Сопряжённость.** Бета — сопряжённое априорное к Бернулли и биномиальному: апостериорное снова бета, обновление сводится к сложению счётчиков. Это делает байесовское обучение **онлайн-вычислимым**.

Итог: бета — не случайный выбор, а естественная модель неопределённости в вероятности.

### Сопряжённость: постановка

Пусть $X \sim \mathrm{Bernoulli}(p)$, но $p$ **неизвестно**. Байесовский подход:

1. **Априорное распределение:** $p \sim \mathrm{Beta}(a,b)$.
2. Наблюдаем данные: $X = x$, где $x \in \{0,1\}$.
3. Хотим найти **апостериорное** распределение $p \mid X = x$.

**Формула Байеса:**
$$f_{p|X}(p \mid x) = \frac{\mathsf{P}(X = x \mid p)\, f_p(p)}{\mathsf{P}(X = x)} \propto \mathsf{P}(X = x \mid p)\, f_p(p).$$

То есть: **апостериорное $\propto$ правдоподобие $\times$ априорное**.

### Сопряжённость: частный случай $x = 1$

Априорное:
$$f_p(p) = \frac{1}{B(a,b)}\, p^{a-1}(1-p)^{b-1}.$$

Правдоподобие при $x = 1$:
$$\mathsf{P}(X = 1 \mid p) = p.$$

Перемножаем:
$$f_{p|X}(p \mid 1) \propto p \cdot p^{a-1}(1-p)^{b-1} = p^{(a+1)-1}(1-p)^{b-1}.$$

Это снова бета-плотность, но с параметрами $(a+1, b)$:
$$p \mid X = 1 \sim \mathrm{Beta}(a+1,\, b).$$

### Сопряжённость: частный случай $x = 0$

Правдоподобие при $x = 0$:
$$\mathsf{P}(X = 0 \mid p) = 1 - p.$$

Перемножаем:
$$f_{p|X}(p \mid 0) \propto (1-p) \cdot p^{a-1}(1-p)^{b-1} = p^{a-1}(1-p)^{(b+1)-1}.$$

Это снова бета-плотность, но с параметрами $(a, b+1)$:
$$p \mid X = 0 \sim \mathrm{Beta}(a,\, b+1).$$

### Сопряжённость: общий случай $n$ испытаний

Пусть $X \sim \mathrm{Bin}(n, p)$, наблюдаем $X = k$ успехов. Правдоподобие:
$$\mathsf{P}(X = k \mid p) = C_n^k\, p^k (1-p)^{n-k} \propto p^k (1-p)^{n-k}.$$

Перемножаем с априорным:
$$f_{p|X}(p \mid k) \propto p^k (1-p)^{n-k} \cdot p^{a-1}(1-p)^{b-1} = p^{(a+k)-1}(1-p)^{(b+n-k)-1}.$$

Это бета-плотность с параметрами $(a+k,\ b+n-k)$:
$$\boxed{\,p \mid X = k \sim \mathrm{Beta}(a+k,\ b+n-k).\,}$$

**Правило обновления:**
$$a \to a + k, \qquad b \to b + (n-k).$$

### Сопряженность: интерпретация

Параметры беты — это «псевдосчетчики»:
- $a$ — сколько «псевдоуспехов» мы видели априори;
- $b$ — сколько «псевдонеудач» мы видели априори.

После наблюдения $k$ успехов и $n-k$ неудач:
$$a_{\text{post}} = a + k, \qquad b_{\text{post}} = b + (n - k).$$

**Сопряженность:** априорное и апостериорное — из одного семейства (бета). Обновление сводится к сложению счетчиков.

*Предсказательное распределение:*
$$\mathrm{P}(X_{n+1} = 1 \mid \text{данные}) = \mathrm{E}[p \mid \text{данные}] = \frac{a + k}{a + b + n}.$$

### Зачем это в ML: байесовский классификатор

Задача: классификатор, который видит поток примеров и **обновляет** оценку вероятности класса.

1. Априорное: $p \sim \mathrm{Beta}(a_0, b_0)$.
2. После $n_1$ примеров класса 1 и $n_0$ примеров класса 0:
$$p \mid \text{данные} \sim \mathrm{Beta}(a_0 + n_1,\; b_0 + n_0).$$
3. Предсказание для нового примера:
$$\mathrm{P}(\text{класс } 1 \mid \text{данные}) = \frac{a_0 + n_1}{a_0 + b_0 + n_1 + n_0}.$$

**Преимущество:**
- онлайн-обновление без пересчета с нуля;
- регуляризация (априорное сглаживание);
- калиброванная неопределенность (ширина беты = уверенность).

### Примеры применения

- **A/B-тест:** сравнение двух вариантов через бета-распределения.
- **CTR-предсказание:** доля кликов, обновляемая онлайн.
- **Spam-фильтр:** дообучение на потоке писем.
- **Рекомендательные системы:** оценка вероятности клика по пользователю.

Во всех случаях: бета-распределение — естественная модель неопределенности в вероятности.

### Итог лекции

- Дискретные распределения образуют дерево: Бернулли $\to$ Биномиальное, Категориальное $\to$ Мультиномиальное.
- Гамма- и бета-функции — инструмент для работы с бета-распределением.
- Бета-распределение: носитель $(0, 1)$, параметры $a, b$ — «псевдосчетчики».
- Сопряженность: Бета — априорное для Бернулли/Биномиального. Обновление: $a \to a + k$, $b \to b + (n - k)$.
- Применение: байесовский классификатор с дообучением, A/B-тест, CTR.

## Задача 1 *(слайд 14)*
В корзине шары трех цветов: красные, зеленые, синие. Априори считаем, что всех цветов поровну. Достали (с возвращением) 10 шаров: 5 красных, 3 зеленых, 2 синих. Вопрос: каково апостериорное распределение долей?

### Решение
Пусть $p = (p_к, p_з, p_с)$ — вектор долей шаров трех цветов. Данные $x = (5, 3, 2)$ — числа вынутых шаров каждого цвета, $n = 10$.

**① Априорное распределение.** «Поровну» означает, что априорное среднее долей $(1/3, 1/3, 1/3)$ и нет никакой информации о данных. Это соответствует равномерному распределению на симплексе, то есть распределению Дирихле:

$$p \sim \mathrm{Dir}(1, 1, 1).$$

**② Данные.** Выборка с возвращением — полиномиальная схема. Наблюдается $x = (5, 3, 2)$, $n = 10$.

**③ Апостериорное распределение.** Распределение Дирихле сопряжено полиномиальному правдоподобию, поэтому апостериор имеет вид $\mathrm{Dir}(1 + x_1,\, 1 + x_2,\, 1 + x_3)$:

$$p \mid \text{данные} \sim \mathrm{Dir}(1+5,\, 1+3,\, 1+2) = \mathrm{Dir}(6, 4, 3).$$

**④ Апостериорные средние.** Для $\mathrm{Dir}(\alpha_1, \alpha_2, \alpha_3)$ с суммой $\alpha = \sum \alpha_i$ имеем $\mathsf{E}[p_i] = \alpha_i / \alpha$. Здесь $\alpha = 6 + 4 + 3 = 13$, поэтому

$$\mathsf{E}[p \mid \text{данные}] = \left(\frac{6}{13},\,\frac{4}{13},\,\frac{3}{13}\right) \approx (0{,}462;\; 0{,}308;\; 0{,}231).$$

**Ответ:** апостериорное распределение долей $p \mid \text{данные} \sim \mathrm{Dir}(6, 4, 3)$, апостериорные средние $\left(\tfrac{6}{13}, \tfrac{4}{13}, \tfrac{3}{13}\right) \approx (0{,}462;\, 0{,}308;\, 0{,}231)$.

## Задача 2 *(слайды 15–16)*
Классифицировать текст по $K$ классам (спам/не спам, тематики, тональность). Модель: документ — последовательность слов $w_1,\dots,w_n$ из словаря $V$; наивное предположение: слова независимы при условии класса. Параметры: $\pi_k = \mathsf{P}(\text{класс } k)$ — априорные вероятности классов; $\theta_{k,v} = \mathsf{P}(\text{слово } v \mid \text{класс } k)$ — вероятности слов в классе $k$; для каждого класса $k$: $\theta_k = (\theta_{k,1},\dots,\theta_{k,V})$ — вектор на симплексе. Ключевой вопрос: как оценить $\theta_k$? Байесовская модель: априорное распределение для каждого класса $k$: $\theta_k \sim \mathrm{Dir}(a_k)$, где $a_k = (a_{k,1},\dots,a_{k,V})$ (если нет предпочтений: $a_{k,v} = 1$ для всех $v$ — равномерное на симплексе). Правдоподобие: пусть $x_{k,v}$ — сколько раз слово $v$ встретилось в документах класса $k$, тогда $P(\{x_{k,v}\} \mid \theta_k) \propto \prod_{v=1}^{V} \theta_{k,v}^{x_{k,v}}$.

### Решение
Документ $d = (w_1,\dots,w_n)$ нужно отнести к одному из $K$ классов. Параметры модели:

- $\pi_k = \mathsf P(\text{класс } k)$ — априорные вероятности классов;
- $\theta_{k,v} = \mathsf P(\text{слово } v \mid \text{класс } k)$, $\sum_v \theta_{k,v} = 1$, т.е. $\theta_k$ лежит на симплексе.

Основной вопрос — байесовская оценка вектора $\theta_k$ по обучающим текстам.

### Шаг 1. Априорное распределение

Возьмём сопряжённое к категориальному правдоподобию распределение — Дирихле. Для каждого класса $k$:

$$\theta_k \sim \mathrm{Dir}(a_k), \qquad a_k = (a_{k,1},\dots,a_{k,V}),$$

с плотностью (на симплексе)

$$p(\theta_k) \propto \prod_{v=1}^V \theta_{k,v}^{a_{k,v}-1}.$$

Если нет предпочтений, берём $a_{k,v} = 1$ для всех $v$ — это равномерное распределение на симплексе.

### Шаг 2. Правдоподобие

Пусть $x_{k,v}$ — число вхождений слова $v$ во всех обучающих документах класса $k$, $N_k = \sum_v x_{k,v}$ — суммарное число слов. В силу наивного предположения (слова независимы в пределах класса; итоговое правдоподобие — мультиномиальное):

$$P(\{x_{k,v}\} \mid \theta_k) \propto \prod_{v=1}^{V} \theta_{k,v}^{x_{k,v}}.$$

Множитель вида $\dfrac{N_k!}{x_{k,1}!\cdots x_{k,V}!}$ не зависит от $\theta_k$, поэтому его можно опустить.

### Шаг 3. Апостериорное распределение

По формуле Байеса:

$$p(\theta_k \mid \text{данные}) \propto p(\text{данные} \mid \theta_k)\, p(\theta_k) \propto \left(\prod_{v=1}^V \theta_{k,v}^{x_{k,v}}\right) \left(\prod_{v=1}^V \theta_{k,v}^{a_{k,v}-1}\right) = \prod_{v=1}^V \theta_{k,v}^{a_{k,v}+x_{k,v}-1}.$$

Это плотность распределения Дирихле с суммарными параметрами $a_{k,v}+x_{k,v}$ (постоянная нормировки автоматически совпадает с нормировочной константой Дирихле). В силу сопряжённости:

$$\theta_k \mid \text{данные} \sim \mathrm{Dir}(a_{k,1}+x_{k,1},\,\dots,\,a_{k,V}+x_{k,V}).$$

Итак, правило обновления знаний при поступлении новых данных:

$$a_{k,v} \;\longrightarrow\; a_{k,v} + x_{k,v}.$$

Параметры $a_{k,v}$ играют роль «виртуальных» наблюдений слов: априорные $a_{k,v}$ складываются с реальными частотами $x_{k,v}$.

### Шаг 4. Итоговые оценки и классификация

В качестве точечной оценки берем апостериорное среднее:

$$\hat\theta_{k,v} = \mathsf E[\theta_{k,v} \mid \text{данные}] = \frac{a_{k,v} + x_{k,v}}{\sum_{v'} (a_{k,v'} + x_{k,v'})}.$$

При $a_{k,v}=1$ это оценка максимального правдоподобия $\dfrac{x_{k,v}}{N_k}$ со сглаживанием (сдвигом Лапласа), что спасает от нулевых вероятностей для слов, не встретившихся в классе.

Аналогично, можно обновлять и априорные вероятности классов (мультиномиальное правдоподобие по числу документов в классе), после чего классификация документа $d$ производится по апостериорным вероятностям классов:

$$\mathsf P(k \mid d) \propto \pi_k \prod_{i=1}^{n} \theta_{k,w_i} = \pi_k \prod_{v} \theta_{k,v}^{n_v(d)},$$

где $n_v(d)$ — частота слова $v$ в документе; выбирается класс $k$ с максимальным значением.

### Ответ

Апостериорное распределение вектора вероятностей слов для класса $k$:

$$\boxed{\;\theta_k \mid \text{данные} \sim \mathrm{Dir}(a_{k,1}+x_{k,1},\,\dots,\,a_{k,V}+x_{k,V})\;}$$

Правило обновления параметров:

$$\boxed{\;a_{k,v} \to a_{k,v} + x_{k,v}\;}$$

точечная оценка — $\hat\theta_{k,v} = \dfrac{a_{k,v}+x_{k,v}}{\sum_{v'}(a_{k,v'}+x_{k,v'})}$.

## Задача 3 *(слайды 23–24)*
Задача 1.1. «Большие данные — большая уверенность?». Априорное распределение: $p \sim \operatorname{Dir}(1,1,1)$. Наблюдали: $x = (0,0,100)$. Вопросы: 1) Какое апостериорное распределение? 2) Какая категория имеет наибольшее апостериорное среднее? 3) Какая категория имеет наибольшую апостериорную дисперсию?

### Решение
Априорное распределение $\operatorname{Dir}(1,1,1)$ сопряжено полиномиальному правдоподобию, поэтому апостериорное распределение равно априорному, где к каждому параметру прибавлено число наблюдений соответствующей категории:

$$p \mid x \sim \operatorname{Dir}(1+0,\;1+0,\;1+100) = \operatorname{Dir}(1,\,1,\,101).$$

### 2) Наибольшее апостериорное среднее

Для $\operatorname{Dir}(\alpha_1,\alpha_2,\alpha_3)$ с $\alpha_0=\alpha_1+\alpha_2+\alpha_3$ средние равны $\mathbb{E}[p_i] = \alpha_i/\alpha_0$. Здесь $\alpha_0 = 1+1+101 = 103$:

$$\mathbb{E}[p_1]=\frac{1}{103},\qquad \mathbb{E}[p_2]=\frac{1}{103},\qquad \mathbb{E}[p_3]=\frac{101}{103}.$$

Наибольшее апостериорное среднее у **третьей категории**: $\mathbb{E}[p_3]\approx 0{,}98$.

### 3) Наибольшая апостериорная дисперсия

Дисперсия компоненты:
$$\operatorname{Var}[p_i] = \frac{\alpha_i(\alpha_0-\alpha_i)}{\alpha_0^2(\alpha_0+1)},\qquad \alpha_0+1 = 104.$$

Считаем:

$$\operatorname{Var}[p_1]=\operatorname{Var}[p_2]=\frac{1\cdot 102}{103^2\cdot 104}\approx 9{,}2\cdot 10^{-5},$$

$$\operatorname{Var}[p_3]=\frac{101\cdot 2}{103^2\cdot 104}\approx 1{,}8\cdot 10^{-4}.$$

Наибольшая апостериорная дисперсия также у **третьей категории** — неопределённость сосредоточена там же, где и почти вся вероятностная масса: хотяndata говорят о третьей категории, дисперсия пропорциональна $\alpha_i(\alpha_0-\alpha_i)$ и максимальна при $\alpha_i$ близком к $\alpha_0/2$ среди данных значений. Ожидаемо небольшая ($\sim 0{,}0002$) — «большие данные дают большую уверенность»: все дисперсии малы из-за множителя $\alpha_0^2(\alpha_0+1)=103^2\cdot 104$.

**Ответ:** $p\mid x \sim \operatorname{Dir}(1,1,101)$; наибольшее среднее и наибольшая дисперсия — у третьей категории, $\mathbb{E}[p_3]=101/103$, $\operatorname{Var}[p_3]=\dfrac{202}{103^2\cdot 104}\approx 1{,}8\cdot 10^{-4}$.

## Задача 4 *(слайды 25–26)*
Задача 1.1 (условие на предыдущих слайдах, в диапазоне — только решение). По условию по данным $x$ вычисляется апостериорное распределение для вектора $p$ при распределении Дирихле; по данным слайдов решение завершается пунктами 1–3.

### Решение
Пусть данные $x$ состоят из $n=100$ наблюдений, все из которых относятся к третьей категории, а априорное распределение — Дирихле с равномерными параметрами $\alpha=(1,1,1)$. По условию вычисляются апостериорное распределение, апостериорные средние и апостериорные дисперсии для $p=(p_1,p_2,p_3)$.

**1. Апостериорное распределение.**

Распределение Дирихле сопряжено полиномиальному правдоподобию: если априорные параметры $\alpha_k$, а в данных $x_k$ наблюдений $k$-й категории, то

$$
p \mid x \sim \mathrm{Dir}(\alpha_k + x_k,\ k=1,2,3).
$$

Счётчики по категориям: $x_1=0$, $x_2=0$, $x_3=100$. Теперь, когда $x=(0,0,100)$, априор $\mathrm{Dir}(1,1,1)$ даёт апостериорное распределение Дирихле:

$$
p \mid x \sim \mathrm{Dir}(1+0,\ 1+0,\ 1+100) = \mathrm{Dir}(1,\ 1,\ 101).
$$

**2. Апостериорные средние.**

Если $p \sim \mathrm{Dir}(a_1,a_2,a_3)$ с $a_0=a_1+a_2+a_3$, то $\mathsf{E}p_k=\dfrac{a_k}{a_0}$. Здесь $a_0=1+1+101=103$, так что

$$
\mathsf{E}p = \left(\frac{1}{103},\ \frac{1}{103},\ \frac{101}{103}\right) \approx (0.0097,\ 0.0097,\ 0.981).
$$

Отметим, что средние уже «сдвинуты» от хороших истинных $\frac{a_k}{a_k+x_k}$-значений к априорным: за счёт априорного параметра $1=1+0$ доли малых категорий стала чуть меньше нуля (выборка $x_1=x_2=0$ «прижата» априором).

**3. Апостериорные дисперсии.**

Для Дирихле $\mathrm{Dir}(a_1,a_2,a_3)$ дисперсия $k$-й компоненты равна

$$
\mathsf{D}p_k = \frac{a_k\,(a_0-a_k)}{a_0^2\,(a_0+1)}, \qquad a_0=a_1+a_2+a_3.
$$

В нашем случае $a_0=103$.

Первая и вторая категории ($a_1=a_2=1$):

$$
\mathsf{D}p_1=\mathsf{D}p_2=\frac{1\cdot(103-1)}{103^2\cdot 104}=\frac{1\cdot 102}{103^2\cdot 104}\approx 9.2\cdot 10^{-5}.
$$

Третья категория ($a_3=101$):

$$
\mathsf{D}p_3=\frac{101\cdot(103-101)}{103^2\cdot 104}=\frac{101\cdot 2}{103^2\cdot 104}\approx 1.8\cdot 10^{-4}.
$$

Итого:

$$
\mathsf{D}p_1=\mathsf{D}p_2\approx 9.2\cdot 10^{-5},\
\qquad
\mathsf{D}p_3\approx 1.8\cdot 10^{-4}.
$$

Апостериорные стандартные отклонения: $\sqrt{\mathsf{D}p_1}\approx 0.0096$, $\sqrt{\mathsf{D}p_3}\approx 0.0135$.

**Вывод.** Хотя наибольший счётчик ($101$) — у третьей категории, апостериорная дисперсия у неё наибольшая: $\mathsf{D}p_3\approx 1.8\cdot 10^{-4}$ против $\approx 9.2\cdot 10^{-5}$ у первых двух. Дело в том, что дисперсия компоненты максимальна при $p_k$ вдали от нуля и уменьшается к краям симплекса: компонента с малым параметром $a_k=1$ концентрирована около нуля с малой дисперсией, а большая неопределённость приходится на «доминирующую» компоненту, вокруг которой и происходит основная параметризация распределения.

## Задача 5 *(слайды 27–29)*
Задача 2.3 «Сумма средних». Пусть $p \sim \mathrm{Dir}(a_1,\dots,a_K)$, $a_0 = \sum_k a_k$. Вопросы: 1) Верно ли, что $\sum_{k=1}^{K} \mathsf{E}p_k = 1$? 2) Верно ли, что $\sum_{k=1}^{K} \mathsf{D}p_k$ есть величина, не зависящая от $a$?

### Решение
Для $p \sim \mathrm{Dir}(a_1,\dots,a_K)$ известно, что $\mathsf{E}p_k = \dfrac{a_k}{a_0}$, где $a_0 = \sum_{k=1}^{K} a_k$. Тогда

$$\sum_{k=1}^{K} \mathsf{E}p_k = \sum_{k=1}^{K} \frac{a_k}{a_0} = \frac{1}{a_0}\sum_{k=1}^{K} a_k = \frac{a_0}{a_0} = 1.$$

**Ответ: верно.** Это, по сути, следствие ограничения $\sum_{k=1}^{K} p_k = 1$: сумма средних компонент всегда равна среднему суммы, то есть единице, при любом выборе параметров $a$.

### Вопрос 2: сумма дисперсий

Для компонент Дирихле известно:

$$\mathsf{D}p_k = \frac{a_k(a_0-a_k)}{a_0^2(a_0+1)}.$$

Просуммируем по всем $k$:

$$\sum_{k=1}^{K} \mathsf{D}p_k = \frac{1}{a_0^2(a_0+1)} \sum_{k=1}^{K} a_k(a_0 - a_k) = \frac{1}{a_0^2(a_0+1)} \left( a_0\sum_{k=1}^{K} a_k - \sum_{k=1}^{K} a_k^2 \right) = \frac{a_0^2 - \sum_{k=1}^{K} a_k^2}{a_0^2(a_0+1)}.$$

Хотя $a_0$ одинаков для всех слагаемых, в числителе остаётся величина $\sum_k a_k^2$, которая зависит от того, как именно распределены параметры по компонентам. Проверим на примерах (при фиксированном $K=3$):

- $a = (1,1,1)$: здесь $a_0 = 3$, $\sum_k a_k^2 = 3$, поэтому

$$\sum_{k=1}^{3} \mathsf{D}p_k = \frac{9-3}{9\cdot 4} = \frac{1}{6} \approx 0.167.$$

- $a = (10,1,1)$: здесь $a_0 = 12$, $\sum_k a_k^2 = 100+1+1 = 102$, поэтому

$$\sum_{k=1}^{3} \mathsf{D}p_k = \frac{144-102}{144\cdot 13} \approx 0.0224.$$

Значения различаются, значит сумма дисперсий не является константой.

**Ответ: неверно.** Величина $\sum_{k=1}^{K} \mathsf{D}p_k = \dfrac{a_0^2 - \sum_k a_k^2}{a_0^2(a_0+1)}$ зависит от формы вектора $a$: чем «острее» распределение (параметры сосредоточены в одной компоненте), тем меньше суммарный разброс компонент.

## Задача 6 *(слайды 30–32)*
Задача 3.1 «Дирихле — это независимые беты?». Пусть $p \sim \mathrm{Dir}(a_1,\dots,a_K)$. Вопросы: 1) Верно ли, что каждая компонента $p_k$ имеет маргинальное распределение $\mathrm{Beta}(a_k,\,a_0-a_k)$? 2) Верно ли, что компоненты $p_1,\dots,p_K$ независимы?

### Решение
Пусть $p \sim \mathrm{Dir}(a_1,\dots,a_K)$, то есть

$$f(p_1,\dots,p_K)=\frac{1}{B(a_1,\dots,a_K)}\prod_{k=1}^{K}p_k^{a_k-1},\qquad p_k\ge 0,\ \sum_{k=1}^K p_k=1,$$

где $a_0=\sum_{k=1}^K a_k$ и $B(a_1,\dots,a_K)=\frac{\prod_k \Gamma(a_k)}{\Gamma(a_0)}$ — нормировочная константа.

### 1) Маргинальное распределение компоненты $p_k$

Проинтегрируем совместную плотность по всем остальным компонентам. Используем агрегационное свойство Дирихле: если $p\sim\mathrm{Dir}(a_1,\dots,a_K)$, то группа компонент $(p_k)$ и сумма остальных $(1-p_k)=\sum_{j\ne k}p_j$ образуют бинарное разбиение с параметрами $(a_k,\ a_0-a_k)$. Формально, интеграл

$$f_k(x)=\int f(p_k=x,\,p_{-k})\,dp_{-k}$$

по симплексу (здесь удобно параметризовать $p_{-k}$ через $K-1$ свободную переменную) даёт

$$f_k(x)=\frac{\Gamma(a_0)}{\Gamma(a_k)\Gamma(a_0-a_k)}\,x^{a_k-1}(1-x)^{a_0-a_k-1},\qquad x\in[0,1].$$

Это в точности плотность бета-распределения с параметрами $(a_k,\ a_0-a_k)$:

$$p_k\sim\mathrm{Beta}(a_k,\ a_0-a_k).$$

**Вывод:** утверждение верно.

Отсюда, в частности, следуют моменты:
$$\mathbb E[p_k]=\frac{a_k}{a_0},\qquad
\mathrm{Var}(p_k)=\frac{a_k(a_0-a_k)}{a_0^2(a_0+1)}.$$

### 2) Независимость компонент

Интуиция подсказывает обратное: раз $\sum_k p_k=1$, компоненты связаны жёстким ограничением — увеличение одной обязано уменьшать сумму остальных. Значит, независимости быть не может (кроме вырожденных случаев). Проверим это вычислением ковариации.

Используем то же свойство агрегации: пара $(p_k,\ p_j,\ \sum_{i\ne k,j}p_i)$ распределена как $\mathrm{Dir}(a_k,\ a_j,\ a_0-a_k-a_j)$. Применяя результат пункта 1 к тройке, получаем:

$$\mathbb E[p_kp_j]=\frac{a_k a_j}{a_0(a_0+1)}\quad\Longrightarrow\quad \mathrm{Cov}(p_k,p_j)=\frac{a_ka_j}{a_0(a_0+1)}-\frac{a_k}{a_0}\cdot\frac{a_j}{a_0}=-\frac{a_ka_j}{a_0^2(a_0+1)}.$$

Итак,
$$\mathrm{Cov}(p_k,\,p_j)=-\frac{a_k a_j}{a_0^2\,(a_0+1)}\neq 0\qquad (k\neq j,\ a_k,a_j>0).$$

Ковариация строго отрицательна: компоненты антикоррелированы и, следовательно, **зависимы** (непрерывные величины с ненулевой ковариацией не могут быть независимыми).

**Вывод:** утверждение неверно. Дирихле — «не независимые беты»: маргинально каждая компонента бета-распределена, но между компонентами есть отрицательная связь, обязанная условию нормировки $\sum_k p_k=1$.

## Задача 7 *(слайд 33)*
Задача 3.1 (продолжение решения): проверить утверждения о распределении Дирихле: 1) маргинальные распределения $p_k \sim \operatorname{Beta}(a_k,\, a_0 - a_k)$; 2) компоненты $p_k$ независимы.

### Решение
Вектор $(p_1,\dots,p_K)$ имеет распределение Дирихле $\operatorname{Dir}(a_1,\dots,a_K)$ с плотностью на симплексе $\{p_k\ge 0,\ \sum_k p_k = 1\}$:

$$
f(p_1,\dots,p_K) = \frac{\Gamma(a_0)}{\prod_k \Gamma(a_k)} \prod_{k=1}^K p_k^{a_k - 1}, \qquad a_0 = \sum_{k=1}^K a_k .
$$

Проверим два утверждения.

### 1) Маргинальные распределения

Докажем, что $p_k \sim \operatorname{Beta}(a_k,\, a_0 - a_k)$. Для этого проинтегрируем совместную плотность по всем компонентам, кроме $p_k$.

Переобозначим: пусть $x = p_k$, а $s = 1 - x = \sum_{j\ne k} p_j$. Проще всего сделать замену переменных $p_j = s\, t_j$ для $j\ne k$, где $(t_j)_{j\ne k}$ — точки симплекса размерности $K-2$: $\sum_{j\ne k} t_j = 1$, $t_j\ge 0$. Якобиан этой замены равен $s^{K-2}$. Тогда

$$
\sum_{j \ne k} p_j^{a_j-1} = s^{\sum_{j\ne k} a_j - (K-1)} \prod_{j\ne k} t_j^{a_j - 1} = s^{(a_0 - a_k) - (K-1)} \prod_{j\ne k} t_j^{a_j-1},
$$

а множитель $s^{K-2}$ от якобиана даёт в сумме степень $s^{a_0 - a_k - 1}$, так как $a_0 - a_k - (K-1) + (K-2) = a_0 - a_k - 1$.

Следовательно, маргинальная плотность

$$
f_k(x) = \frac{\Gamma(a_0)}{\Gamma(a_k)} \, x^{a_k - 1} \int x \text{ (без } p_k\text{)} \cdots = \frac{\Gamma(a_0)}{\Gamma(a_k)\,\Gamma(a_0-a_k)}\, x^{a_k-1} (1-x)^{a_0 - a_k - 1},
$$

поскольку интеграл по $(t_j)$, $j\ne k$, дает нормировочную константу, обратную $B(a_1/x,\dots)$ — аккуратно:

$$
\int_{\substack{t_j\ge 0\\ \sum_{j\ne k} t_j = 1}} \prod_{j\ne k} t_j^{a_j-1}\, dt_1\cdots dt_{K-2} = \frac{\prod_{j\ne k}\Gamma(a_j)}{\Gamma(a_0 - a_k)} .
$$

Тогда

$$
f_k(x) = \frac{\Gamma(a_0)}{\Gamma(a_k)} x^{a_k-1} \cdot \frac{\prod_{j\ne k}\Gamma(a_j)}{\Gamma(a_0-a_k)} \, x^{a_k-1}\text{-степени уже учтены}\, \Rightarrow\ f_k(x) = \frac{x^{a_k-1}(1-x)^{a_0-a_k-1}}{B(a_k,\, a_0-a_k)} ,
$$

где использовано $\Gamma(a_0)\prod_{j\ne k}\Gamma(a_j) \cdot \frac{1}{\Gamma(a_k)\Gamma(a_0-a_k)} \cdot \Gamma(a_k)\prod_{j\ne k}\Gamma(a_j)$ — упрощая:

$$
\frac{\Gamma(a_0)}{\Gamma(a_k)} \cdot \frac{\prod_{j\ne k}\Gamma(a_j)}{\Gamma(a_0 - a_k)} = \frac{\prod_{j}\Gamma(a_j)}{\Gamma(a_k)\Gamma(a_0-a_k)} \cdot \Gamma(a_0)\cdot\frac{1}{\prod_j \Gamma(a_j)}\cdot\Gamma(a_k)\prod_{j\ne k}\Gamma(a_j)\Big/ \cdots = \frac{1}{B(a_k, a_0 - a_k)} .
$$

Итог: плотность маргинального распределения

$$
f_k(x) = \frac{1}{B(a_k,\, a_0 - a_k)}\, x^{a_k - 1} (1 - x)^{a_0 - a_k - 1}, \qquad 0 \le x \le 1,
$$

то есть утверждение 1) **верно**: $p_k \sim \operatorname{Beta}(a_k,\, a_0 - a_k)$. Заметим, что $a_0 - a_k = \sum_{j \ne k} a_j > 0$ (при $K \ge 2$), так что параметры корректны.

### 2) Независимость компонентов

Утверждение: компоненты $p_k$ независимы. Проверим через ковариации.

Сначала найдём второй момент. По тому же приему, что и выше (интегрирование с заменой $p_k = x$, $p_j = s\,t_j$), полный момент:

$$
\mathbb{E}[p_k^2] = \frac{a_k(a_k+1)}{a_0 (a_0+1)}.
$$

Значит,

$$
\operatorname{Var}(p_k) = \mathbb{E}[p_k^2] - (\mathbb{E} p_k)^2 = \frac{a_k (a_k+1)}{a_0(a_0+1)} - \frac{a_k^2}{a_0^2} = \frac{a_k (a_0 - a_k)}{a_0^2 (a_0 + 1)},
$$

что совпадает с дисперсией $\operatorname{Beta}(a_k, a_0 - a_k)$.

Аналогично вычисляется смешанный второй момент (интегрирование плотности с $p_j^2 p_k^2$-подобной заменой — стандартная формула для моментов Дирихле):

$$
\mathbb{E}[p_j p_k] = \frac{a_j a_k}{a_0 (a_0 + 1)}, \qquad j \ne k .
$$

Тогда ковариация

$$
\operatorname{Cov}(p_j, p_k) = \mathbb{E}[p_j p_k] - \mathbb{E}p_j \, \mathbb{E}p_k = \frac{a_j a_k}{a_0(a_0+1)} - \frac{a_j}{a_0}\cdot\frac{a_k}{a_0} = \frac{a_j a_k}{a_0^2}\left(\frac{a_0}{a_0+1} - 1\right) = -\frac{a_j a_k}{a_0^2 (a_0 + 1)} .
$$

При $a_j, a_k > 0$ и $j \ne k$ выполнено

$$
\operatorname{Cov}(p_j, p_k) = -\frac{a_j a_k}{a_0^2(a_0+1)} \ne 0,
$$

поэтому компоненты **зависимы**: утверждение 2) **неверно**.

Причина зависимости видна из самого носителя распределения: поддерживающее множество — симплекс $\sum_k p_k = 1$, жёсткое ограничение связывает все компоненты. Если одна компонента принимает большое значение, остальные вынуждены быть малыми. Именно поэтому ковариация отрицательна. Формально: если бы компоненты были независимы, то совместная плотность равнялась бы произведению маргинальных (произведению бета-плотностей) на всём $[0,1]^K$, что не совпадает с плотностью Дирихле, сосредоточенной на симплексе (который имеет нулевую меру Лебега в $\mathbb{R}^K$).

Вывод: маргинальные распределения $p_k \sim \operatorname{Beta}(a_k, a_0-a_k)$, но совместное распределение — Дирихле на симплексе, а не произведение бета-распределений; компоненты зависимы.

## Задача 8 *(слайды 34–35)*
Распределение хи-квадрат: пусть $Z_1, \dots, Z_n$ — независимые стандартные нормальные величины $Z_i \sim \mathcal{N}(0,1)$. Показать/описать, что величина $\chi_n^2 = Z_1^2 + Z_2^2 + \dots + Z_n^2$ имеет распределение хи-квадрат с $n$ степенями свободы; найти её плотность.

### Решение
Пусть $Z_1,\dots,Z_n$ — независимые случайные величины со стандартным нормальным распределением: $Z_i \sim \mathcal{N}(0,1)$. Рассмотрим величину

$$\chi_n^2 = Z_1^2 + Z_2^2 + \dots + Z_n^2.$$

По определению она имеет **распределение хи-квадрат с $n$ степенями свободы**: $\chi_n^2 \sim \chi^2(n)$. Смысл распределения — сумма квадратов $n$ независимых стандартных нормальных величин.

### Шаг 1. Плотность квадрата нормальной величины ($n=1$)

Пусть $Y = Z^2$, где $Z \sim \mathcal{N}(0,1)$. Функция распределения при $x > 0$:

$$F_Y(x) = P(Z^2 \le x) = P(-\sqrt{x} \le Z \le \sqrt{x}) = 2\Phi(\sqrt{x}) - 1,$$

где $\Phi$ — функция распределения стандартной нормальной величины. Дифференцируя по $x$:

$$f_Y(x) = 2\,\varphi(\sqrt{x})\cdot \frac{1}{2\sqrt{x}} = \frac{1}{\sqrt{x}}\cdot \frac{1}{\sqrt{2\pi}} e^{-x/2} = \frac{1}{\sqrt{2\pi}}\, x^{-1/2} e^{-x/2}, \quad x > 0.$$

Это плотность $\Gamma(1/2,\,2)$-распределения, поскольку $\Gamma(1/2) = \sqrt{\pi}$: нормирующая константа $\frac{1}{2^{1/2}\Gamma(1/2)} = \frac{1}{\sqrt{2\,\pi\cdot 2/2}}$... точнее: $\frac{1}{2^{1/2}\sqrt{\pi}} = \frac{1}{\sqrt{2\pi}}$ — совпадает.

### Шаг 2. Сведение к гамма-распределению

Плотность гамма-распределения с формой $\alpha$ и масштабом $\beta$:

$$f(x) = \frac{1}{\beta^{\alpha}\Gamma(\alpha)}\, x^{\alpha-1} e^{-x/\beta}, \quad x > 0.$$

Плотность квадрата нормальной величины — это $\operatorname{Gamma}(\alpha = 1/2,\ \beta = 2)$. Ключевое свойство гамма-распределения: если $X \sim \operatorname{Gamma}(\alpha_1,\beta)$ и $Y \sim \operatorname{Gamma}(\alpha_2,\beta)$ независимы, то $X+Y \sim \operatorname{Gamma}(\alpha_1+\alpha_2,\beta)$ (сворачивание плотностей — свёртка гамма-плотностей с общим масштабом снова даёт гамма-плотность, что следует, например, из характеристических функций: $\varphi_X(t) = (1-\beta i t)^{-\alpha}$, и произведение таких множителей для одинаковых $\beta$ имеет нужный вид).

Так как величины $Z_i^2$ независимы и каждая имеет распределение $\operatorname{Gamma}(1/2,\,2)$, то

$$\chi_n^2 = \sum_{i=1}^n Z_i^2 \sim \operatorname{Gamma}\Big(\underbrace{\tfrac{1}{2}+\dots+\tfrac{1}{2}}_{n},\ 2\Big) = \operatorname{Gamma}\Big(\frac{n}{2},\ 2\Big).$$

Это и означает, что $\chi_n^2 \sim \chi^2(n)$; распределение хи-квадрат — частный случай гамма-распределения.

### Шаг 3. Плотность

Подставляя $\alpha = n/2$, $\beta = 2$ в формулу гамма-плотности, получаем плотность хи-квадрат: для $x > 0$

$$f_{\chi_n^2}(x) = \frac{1}{2^{n/2}\,\Gamma(n/2)}\, x^{n/2-1} e^{-x/2},$$

и $f_{\chi_n^2}(x) = 0$ при $x \le 0$. Здесь $\Gamma(s) = \int_0^\infty t^{s-1}e^{-t}\,dt$ — гамма-функция.

**Проверка нормировки.** Подставим $t = x/2$:

$$\int_0^\infty \frac{1}{2^{n/2}\Gamma(n/2)}\, x^{n/2-1}e^{-x/2}\,dx = \frac{2^{n/2}}{2^{n/2}\Gamma(n/2)}\int_0^\infty t^{n/2-1}e^{-t}\,dt = \frac{\Gamma(n/2)}{\Gamma(n/2)} = 1.$$

### Шаг 4. Частные случаи (проверка)

**$n=1$:**
$$f_{\chi_1^2}(x) = \frac{1}{2^{1/2}\Gamma(1/2)}\,x^{-1/2}e^{-x/2} = \frac{1}{\sqrt{2\pi}}\,x^{-1/2}e^{-x/2}, \quad x>0,$$
— в точности плотность квадрата стандартной нормальной величины, выведенная в шаге 1.

**$n=2$:**
$$f_{\chi_2^2}(x) = \frac{1}{2^{1}\Gamma(1)}\,x^{0}e^{-x/2} = \frac{1}{2}e^{-x/2}, \quad x>0,$$
— экспоненциальное распределение с параметром $1/2$ (заметим, что $\chi_2^2 = Z_1^2+Z_2^2$ — квадрат радиуса случайной точки стандартного нормального распределения на плоскости, и экспоненциальность согласуется с равномерным распределением угла).

### Итог

$$\boxed{\;\chi_n^2 = Z_1^2 + \dots + Z_n^2 \sim \chi^2(n) = \operatorname{Gamma}\Big(\frac{n}{2},\,2\Big), \qquad f_{\chi_n^2}(x) = \frac{1}{2^{n/2}\Gamma(n/2)}\, x^{n/2-1} e^{-x/2},\; x>0.\;}$$

## Задача 9 *(слайд 36)*
Свойства распределения хи-квадрат: найти числовые характеристики, доказать аддитивность и асимптотику распределения $\chi_n^2$.

### Решение
**Постановка.** Распределение $\chi_n^2$ — это распределение суммы квадратов $n$ независимых стандартных нормальных величин:
$$\chi_n^2 = X_1^2 + \dots + X_n^2, \qquad X_1,\dots,X_n \overset{\text{i.i.d.}}{\sim} \mathcal{N}(0,1).$$

### 1. Числовые характеристики

Вычислим сначала моменты одной случайной величины $Y = X^2$, где $X \sim \mathcal{N}(0,1)$.

**Математическое ожидание.**
$$\operatorname{E}X^2 = \operatorname{E}X^2 - (\operatorname{E}X)^2 + (\operatorname{E}X)^2 = \operatorname{D}X + (\operatorname{E}X)^2 = 1 + 0 = 1.$$

**Дисперсия.** Нужно $\operatorname{E}X^4$. Используем интегрирование по частям:
$$\operatorname{E}X^4 = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} x^4 e^{-x^2/2}\, dx.$$
Пусть $u = 2x^3$, $dv = xe^{-x^2/2}dx$, откуда $v = -e^{-x^2/2}$. Тогда
$$\int_{-\infty}^{\infty} x^4 e^{-x^2/2} dx = \frac{1}{\sqrt{2\pi}}\Bigl[-2x^3 e^{-x^2/2}\Bigr]_{-\infty}^{\infty} + \int_{-\infty}^{\infty} 6x^2 e^{-x^2/2} dx = 0 + 6\operatorname{E}X^2 = 6.$$
(внесение множителя $\frac{1}{\sqrt{2\pi}}$ — множитель плотности стоит при обоих интегралах, поэтому $\operatorname{E}X^4 = 6\operatorname{E}X^2 = 6\cdot 1 = 3\cdot 2 \cdot 1$: вообще $\operatorname{E}X^{2k} = (2k-1)!!$.)

Итак,
$$\operatorname{E}X^4 = 3 \quad \Rightarrow \quad \operatorname{D}(X^2) = \operatorname{E}X^4 - (\operatorname{E}X^2)^2 = 3 - 1 = 2.$$

Теперь для $\chi_n^2 = X_1^2 + \dots + X_n^2$, пользуясь независимостью слагаемых:
$$\operatorname{E}\chi_n^2 = \sum_{k=1}^n \operatorname{E}X_k^2 = n, \qquad \operatorname{D}\chi_n^2 = \sum_{k=1}^n \operatorname{D}X_k^2 = 2n.$$

$$\boxed{\ \operatorname{E}\chi_n^2 = n, \qquad \operatorname{D}\chi_n^2 = 2n.\ }$$

### 2. Аддитивность

Пусть $\chi_m^2$ и $\chi_n^2$ независимы. По определению их можно представить как
$$\chi_m^2 = X_1^2 + \dots + X_m^2, \qquad \chi_n^2 = Y_1^2 + \dots + Y_n^2,$$
где все величины $X_1,\dots,X_m, Y_1,\dots,Y_n$ — независимые стандартные нормальные. Тогда
$$\chi_m^2 + \chi_n^2 = X_1^2 + \dots + X_m^2 + Y_1^2 + \dots + Y_n^2$$
— сумма квадратов $m+n$ независимых стандартных нормальных величин, т.е. по определению снова распределение хи-квадрат с $m+n$ степенями свободы:
$$\boxed{\ \chi_m^2 + \chi_n^2 \sim \chi_{m+n}^2.\ }$$

Отметим, что то же следует из характеристических функций: $\varphi_{\chi_n^2}(t) = (1-2it)^{-n/2}$, и произведение $\varphi_{\chi_m^2}\varphi_{\chi_n^2} = (1-2it)^{-(m+n)/2}$ — характеристическая функция $\chi_{m+n}^2$.

### 3. Асимптотика

Представим $\chi_n^2$ как сумму независимых одинаково распределённых слагаемых:
$$\chi_n^2 = \sum_{k=1}^n X_k^2, \qquad \operatorname{E}X_k^2 = 1, \quad \operatorname{D}X_k^2 = 2.$$
По центральной предельной теореме:
$$\frac{\sum_{k=1}^n X_k^2 - n\cdot 1}{\sqrt{n\cdot 2}} \xrightarrow{d} \mathcal{N}(0,1),$$
то есть
$$\boxed{\ \frac{\chi_n^2 - n}{\sqrt{2n}} \xrightarrow{d} \mathcal{N}(0,1).\ }$$

Таким образом, при больших $n$ распределение $\chi_n^2$ с хорошей точностью приближается нормальным: $\chi_n^2 \approx \mathcal{N}(n,\,2n)$.

## Задача 10 *(слайд 37)*
Распределение Стьюдента: пусть $Z \sim \mathcal{N}(0,1)$ и $V \sim \chi_n^2$ независимы. Показать/описать, что величина $t_n = \dfrac{Z}{\sqrt{V/n}}$ имеет распределение Стьюдента с $n$ степенями свободы ($t_n \sim t(n)$).

### Решение
Пусть $Z \sim \mathcal{N}(0,1)$, $V \sim \chi_n^2$ — независимы. Покажем, что

$$
t_n = \frac{Z}{\sqrt{V/n}}
$$

имеет распределение Стьюдента с $n$ степенями свободы, то есть найдём плотность $t_n$.

### Шаг 1. Плотности $Z$ и $V$

Плотности известны:

$$
f_Z(x) = \frac{1}{\sqrt{2\pi}}\, e^{-x^2/2}, \qquad
f_V(v) = \frac{1}{2^{n/2}\Gamma(n/2)}\, v^{n/2-1} e^{-v/2}, \quad v>0.
$$

Так как $Z$ и $V$ независимы, совместная плотность равна произведению:

$$
f_{Z,V}(x,v) = \frac{1}{\sqrt{2\pi}\, 2^{n/2}\Gamma(n/2)}\, v^{n/2-1} e^{-v/2 - x^2/2}, \quad x\in\mathbb{R},\ v>0.
$$

### Шаг 2. Замена переменных

Возьмём координаты $(w, v)$, где

$$
w = \frac{x}{\sqrt{v/n}} \quad\Longleftrightarrow\quad x = w\sqrt{v/n}.
$$

Это линейная по $x$ замена, якобиан:

$$
\left|\frac{\partial x}{\partial w}\right| = \sqrt{\frac{v}{n}}.
$$

### Шаг 3. Плотность $t_n$

Вычисляем при $w=t$, $v>0$:

$$
f_{W}(t) = \int_0^\infty f_{Z,V}\!\left(t\sqrt{\tfrac{v}{n}},\, v\right)\sqrt{\tfrac{v}{n}}\, dv
= C \int_0^\infty v^{n/2-1} \exp\!\left\{-\frac{v}{2}\left(1+\frac{t^2}{n}\right)\right\} v^{1/2}\, dv,
$$

$$
f_W(t) = C \int_0^\infty v^{(n+1)/2 - 1} \exp\!\left\{-\frac{v}{2}\cdot\frac{n+t^2}{n}\right\} dv,
$$

где $C = \dfrac{1}{\sqrt{2\pi}\, 2^{n/2}\Gamma(n/2)\sqrt{n}}$.

Используем $\int_0^\infty v^{\alpha-1}e^{-\lambda v}dv = \Gamma(\alpha)/\lambda^\alpha$ с $\alpha=\frac{n+1}{2}$, $\lambda=\frac{n+t^2}{2n}$:

$$
f_{t_n}(t) = \frac{1}{\sqrt{2\pi}\,2^{n/2}\Gamma(n/2)\sqrt{n}} \cdot \frac{\Gamma\!\left(\frac{n+1}{2}\right)}{\left(\frac{n+t^2}{2n}\right)^{(n+1)/2}}
= \frac{\sqrt{n}\, 2^{(n+1)/2}}{\sqrt{2\pi}\, 2^{n/2}\sqrt{n}}\cdot \frac{\Gamma\!\left(\frac{n+1}{2}\right)}{\Gamma(n/2)}\,(1+t^2/n)^{-(n+1)/2}
$$

$$
\boxed{\,f_{t_n}(t) = \frac{\Gamma\!\left(\frac{n+1}{2}\right)}{\sqrt{\pi n}\,\Gamma(n/2)}\left(1+\frac{t^2}{n}\right)^{-\frac{n+1}{2}},\quad t\in\mathbb{R}\,}
$$

Это в точности плотность распределения Стьюдента с $n$ степенями свободы: плотность зависит от $t$ через $1+t^2/n$, симметрична, при $n\to\infty$ стремится к $\varphi(t)$ — плотности $\mathcal{N}(0,1)$ (поскольку $(1+t^2/n)^{-(n+1)/2}\to e^{-t^2/2}$).

### Смысл

Величина $t_n = Z/\sqrt{V/n}$ — отношение стандартной нормальной величины к корню из независимой хи-квадрат, делённой на число степеней свободы.

**Статистический контекст.** Если $X_1,\dots,X_m$ — выборка из $\mathcal{N}(\mu,\sigma^2)$, то $\bar X\sim\mathcal{N}(\mu,\sigma^2/m)$, т.е. $Z=\frac{\bar X-\mu}{\sigma/\sqrt m}\sim\mathcal{N}(0,1)$, а выборочная дисперсия $S^2=\frac1{m-1}\sum(X_i-\bar X)^2$ даёт $\frac{(m-1)S^2}{\sigma^2}\sim\chi^2_{m-1}$, причём $\bar X$ и $S^2$ независимы. Тогда

$$
\frac{\bar X-\mu}{S/\sqrt m} = \frac{Z}{\sqrt{V/(m-1)}} \sim t(m-1).
$$

Поэтому отношение «среднее / стандартная ошибка» имеет распределение Стьюдента — что и используется для построения доверительных интервалов и критериев при неизвестной дисперсии.

## Задача 11 *(слайд 38)*
Найти плотность распределения Стьюдента $t_n$ и исследовать её свойства.

### Решение
Пусть $X \sim N(0,1)$, $Y \sim \chi^2_n$ независимы; тогда $t_n = X/\sqrt{Y/n}$ имеет распределение Стьюдента.

Плотности сомножителей:
$$f_X(x) = \frac{1}{\sqrt{2\pi}}\,e^{-x^2/2}, \qquad f_Y(y) = \frac{1}{2^{n/2}\Gamma(n/2)}\,y^{n/2-1}e^{-y/2}, \; y>0.$$

Пусть $t = x/\sqrt{y/n}$, т.е. $y = n x^2/t^2$, и якобиан замены $(x,y)\to(t,y)$:
$$\left|\frac{\partial x}{\partial t}\right| = \frac{\sqrt{y}}{\sqrt{n}}, \qquad \left|\frac{\partial x}{\partial y}\right| = \frac{|t|}{2n}.$$

Тогда совместная плотность в переменных $(t,y)$:
$$g(t,y) = \frac{1}{\sqrt{2\pi}\,2^{n/2}\Gamma(n/2)}\,\frac{\sqrt{y}}{\sqrt{n}}\;\exp\!\left\{-\frac{t^2}{2}\cdot\frac{y}{n}\right\}\frac{1}{2^{n/2}\Gamma(n/2)}\,y^{n/2-1}e^{-y/2}.$$

Интегрируем по $y>0$ (после нормировки константа вычисляется по условию $\int g\,dt\,dy=1$; для удобства вычислим несобственный интеграл отдельно):
$$\int_0^\infty y^{\frac{n-1}{2}} \exp\!\left\{-\frac{y}{2}\left(1+\frac{t^2}{n}\right)\right\} dy = \frac{2^{\frac{n+1}{2}}\Gamma\!\left(\frac{n+1}{2}\right)}{\left(1+\frac{t^2}{n}\right)^{\frac{n+1}{2}}}.$$

Итоговая плотность:
$$f_{t_n}(t) = \frac{\Gamma\!\left(\frac{n+1}{2}\right)}{\sqrt{n\pi}\,\Gamma\!\left(\frac{n}{2}\right)}\left(1+\frac{t^2}{n}\right)^{-\frac{n+1}{2}}, \qquad t\in\mathbb{R}.$$

(Константа в allegation следует из формулы удвоения гамма-функции $\Gamma(z)\Gamma(z+\tfrac12) = 2^{1-2z}\sqrt{\pi}\,\Gamma(2z)$ при $z=\tfrac{n}{2}$.)

### Свойства плотности

**1. Симметрия.** Так как плотность зависит только от $t^2$:
$$f_{t_n}(-t) = f_{t_n}(t) \quad\Longrightarrow\quad t_n \overset{d}{=} -t_n,$$
т.е. распределение симметрично относительно $0$.

**2. Тяжёлые хвосты.** При $|t|\to\infty$ плотность ведёт себя как
$$f_{t_n}(t) \sim C\,|t|^{-(n+1)},$$
т.е. как степенная функция с показателем $-(n+1)$, тогда как у нормального распределения хвосты убывают экспоненциально быстро, $e^{-t^2/2}$. Поэтому моменты $t_n$ конечны лишь при порядке $k<n$; в частности, при $n=1$ не существует даже математического ожидания.

**3. Случай $n=1$ (Коши).** Подставим $n=1$:
$$f_{t_1}(t) = \frac{\Gamma(1)}{\sqrt{\pi}\,\Gamma(1/2)}(1+t^2)^{-1} = \frac{1}{\pi(1+t^2)},$$
— стандартное распределение Коши.

**4. Предельный переход $n\to\infty$.** При каждом фиксированном $t$:
$$\left(1+\frac{t^2}{n}\right)^{-\frac{n+1}{2}} \longrightarrow e^{-t^2/2},$$
а константа нормировки (по формуле Стирлинга для гамма-функции)
$$\frac{\Gamma\!\left(\frac{n+1}{2}\right)}{\sqrt{n\pi}\,\Gamma(n/2)} \longrightarrow \frac{1}{\sqrt{2\pi}}.$$
Следовательно,
$$f_{t_n}(t) \longrightarrow \frac{1}{\sqrt{2\pi}}\,e^{-t^2/2}$$
— плотности $t_n$ сходятся поточечно к плотности стандартного нормального распределения (и $t_n \Rightarrow N(0,1)$).

**Ответ:** плотность распределения Стьюдента
$$f_{t_n}(x) = \frac{\Gamma\!\left(\frac{n+1}{2}\right)}{\sqrt{n\pi}\,\Gamma\!\left(\frac{n}{2}\right)} \left(1 + \frac{x^2}{n}\right)^{-\frac{n+1}{2}}, \quad x \in \mathbb{R}.$$
Она симметрична относительно $0$, тяжелохвостая (хвосты степенные, тяжелее нормальных), при $n=1$ даёт распределение Коши, а при $n\to\infty$ сходится к стандартному нормальному.

## Задача 12 *(слайд 39)*
Свойства распределения Стьюдента: найти числовые характеристики, исследовать симметрию и сходимость к нормальному.

### Решение
Пусть $t_n$ — случайная величина, имеющая распределение Стьюдента с $n$ степенями свободы. Напомним её определение через конструкцию

$$t_n = \frac{Z}{\sqrt{\chi_n^2 / n}},$$

где $Z \sim \mathcal{N}(0,1)$, а $\chi_n^2$ — независимая от $Z$ случайная величина с распределением хи-квадрат с $n$ степенями свободы. Плотность распределения Стьюдента имеет вид

$$f_n(x) = c_n \left(1 + \frac{x^2}{n}\right)^{-\frac{n+1}{2}}, \qquad x \in \mathbb{R},$$

где $c_n > 0$ — нормирующая константа. Исследуем её числовые характеристики, симметрию и предельное поведение.

### 1. Числовые характеристики

В силу свойств стандартного нормального закона и хи-квадрат справедливы女主 формулы:

$$\operatorname{E}t_n = 0 \quad (n > 1), \qquad \operatorname{D}t_n = \frac{n}{n-2} \quad (n > 2).$$

Поясним, почему эти характеристики существуют не при всех $n$.

**Математическое ожидание.** Интеграл

$$\operatorname{E}t_n = \int_{-\infty}^{\infty} x \, f_n(x)\, dx$$

сходится абсолютно только если хвосты $|x| f_n(x)$ интегрируемы, т.е. при показателе степени $\frac{n+1}{2} > 2$, то есть при $n > 1$. При $n = 1$ распределение Стьюдента совпадает с распределением Коши, у которого математическое ожидание **не существует** (хвосты слишком тяжёлые: $f_1(x) \sim \frac{1}{\pi x^2}$ при $|x| \to \infty$, и интеграл $\int |x| f_1(x)\,dx$ расходится).

Отметим, что сам факт $\operatorname{E}t_n = 0$ (при $n>1$) сразу следует из симметрии плотности: $f_n(x)$ — чётная функция, поэтому $\operatorname{E}t_n = 0$, если интеграл сходится.

**Дисперсия.** Для дисперсии нужно существование второго момента:

$$\operatorname{E} t_n^2 = \int_{-\infty}^{\infty} x^2 f_n(x)\, dx < \infty,$$

что требует $\frac{n+1}{2} > 3$, т.е. $n > 2$. При $n = 2$ дисперсия **не существует** — хвосты distribution слишком тяжёлые.

При $n > 2$ второй момент равен

$$\operatorname{E}t_n^2 = \frac{n}{n-2},$$

и так как $\operatorname{E}t_n = 0$, то

$$\operatorname{D}t_n = \operatorname{E}t_n^2 - (\operatorname{E}t_n)^2 = \frac{n}{n-2}.$$

**Поведение дисперсии при росте $n$.** При $n > 2$ дисперсия конечна, причём

$$\operatorname{D}t_n = \frac{n}{n-2} = 1 + \frac{2}{n-2} \to 1 \quad \text{при } n \to \infty.$$

Функция $\frac{n}{n-2}$ монотонно убывает с ростом $n$:

$$\frac{n+1}{n-1} < \frac{n}{n-2},$$

так что дисперсия убывает к $1$ — дисперсии стандартного нормального закона. Это отражает тот факт, что распределение Стьюдента «сжимается» к $\mathcal{N}(0,1)$ по мере увеличения числа степеней свободы.

### 2. Симметрия

Плотность $f_n(x)$ — чётная функция: $f_n(-x) = f_n(x)$, поскольку она зависит только от $x^2$. Отсюда:

- распределение Стьюдента **симметрично** относительно нуля: для любого $x$
  $$\operatorname{P}(t_n \le -x) = \operatorname{P}(t_n \ge x) = 1 - F_n(x),$$
  где $F_n$ — функция распределения $t_n$;
- медиана и (при $n>1$) математическое ожидание равны $0$;
- все нечётные моменты (если они существуют) равны нулю: $\operatorname{E}t_n^{2k+1} = 0$;
- распределение $t_n$ совпадает с распределением $-t_n$; в частности, квантили симметричны: $t_{n,\alpha} = -t_{n,1-\alpha}$, где $t_{n,\alpha}$ — квантиль уровня $\alpha$.

Кроме того, симметрию можно вывести прямо из определения: так как $Z$ симметрична ($Z \overset{d}{=} -Z$) и не зависит от $\chi_n^2$, то

$$t_n = \frac{Z}{\sqrt{\chi_n^2/n}} \overset{d}{=} \frac{-Z}{\sqrt{\chi_n^2/n}} = -t_n.$$

### 3. Сходимость к нормальному распределению

По закону больших чисел для хи-квадрат:

$$\frac{\chi_n^2}{n} \xrightarrow{p} 1 \quad (n \to \infty),$$

поскольку $\operatorname{E}\chi_n^2 = n$, а $\operatorname{D}\chi_n^2 = 2n \to \infty$, но $\operatorname{D}(\chi_n^2/n) = 2/n \to 0$ (например, по неравенству Чебышёва). Значит, знаменатель в определении $t_n$ сходится по вероятности к $1$, а числитель $Z$ от $n$ не зависит. Тогда по теореме Слуцкого

$$t_n = \frac{Z}{\sqrt{\chi_n^2/n}} \xrightarrow{d} \frac{Z}{1} = Z \sim \mathcal{N}(0,1), \qquad n \to \infty.$$

Итак, при $n \to \infty$

$$\boxed{\,t_n \xrightarrow{d} \mathcal{N}(0,1)\,}$$

— распределение Стьюдента сходится по распределению к стандартному нормальному. Согласуется это и с поведением дисперсии: $\operatorname{D}t_n = \frac{n}{n-2} \to 1 = \operatorname{D}Z$.

### Вывод

- $\operatorname{E}t_n = 0$ существует при $n > 1$; при $n = 1$ (Коши) — не существует.
- $\operatorname{D}t_n = \frac{n}{n-2}$ существует при $n > 2$; при $n = 2$ — не существует; при $n > 2$ дисперсия монотонно убывает к $1$.
- Распределение симметрично относительно нуля ($f_n$ — чётная функция).
- При $n \to \infty$ имеем сходимость по распределению $t_n \xrightarrow{d} \mathcal{N}(0,1)$ (по теореме Слуцкого из ЗБЧ для $\chi_n^2/n$).

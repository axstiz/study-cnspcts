### Мотивировка и план лекции

Ранее мы изучили распределение случайной величины, функцию распределения. В реальных задачах, как правило, приходится изучать не одну случайную величину, а несколько. Это может быть семейство случайных величин или их последовательность. Изучая совместное поведение нескольких случайных величин, мы сталкиваемся с принципиально новыми явлениями и сложностями.

План лекции:
1. Функция совместного распределения
2. Независимость случайных величин

### Системы случайных величин

Пусть случайные величины $\xi_1, \ldots, \xi_n$ заданы на одном вероятностном пространстве $\langle \Omega, \mathcal{F}, \mathsf{P} \rangle$.

**Определение.** Функция
$$F_{\xi_1, \ldots, \xi_n}(x_1, \ldots, x_n) = \mathsf{P}(\xi_1 < x_1, \ldots, \xi_n < x_n)$$
называется функцией распределения вектора $(\xi_1, \ldots, \xi_n)$ или функцией совместного распределения случайных величин $\xi_1, \ldots, \xi_n$.

### Распределение двумерной дискретной случайной величины

Распределением двумерной дискретной случайной величины $(\xi, \eta)$ называется перечень всех возможных пар $(x_i, y_j)$ и соответствующих вероятностей $p_{ij} = \mathsf{P}(\xi = x_i, \, \eta = y_j)$:

| $\xi \mid \eta$ | $y_1$ | $y_2$ | $\ldots$ | $y_m$ |
|---|---|---|---|---|
| $x_1$ | $p_{11}$ | $p_{12}$ | $\ldots$ | $p_{1m}$ |
| $x_2$ | $p_{21}$ | $p_{22}$ | $\ldots$ | $p_{2m}$ |
| $\ldots$ | $\ldots$ | $\ldots$ | $\ldots$ | $\ldots$ |
| $x_n$ | $p_{n1}$ | $p_{n2}$ | $\ldots$ | $p_{nm}$ |

Зная распределение двумерной случайной величины, можно найти распределение ее составляющих:
$$\mathsf{P}(\xi = x_1) = p_{11} + p_{12} + \ldots + p_{1m}.$$

### Функция распределения дискретной двумерной случайной величины

Закон совместного распределения: $\mathsf{P}(\xi_1 = x_1, \, \xi_2 = x_2)$.

Функция распределения:
$$F_{\xi_1, \xi_2}(x_1, x_2) = \mathsf{P}(\xi_1 < x_1, \, \xi_2 < x_2).$$

### Функция распределения вектора

Функция $F_{\xi_1,\ldots,\xi_n}(x_1,\ldots,x_n) = \mathsf{P}(\xi_1 < x_1,\ \ldots,\ \xi_n < x_n)$ называется функцией распределения вектора $(\xi_1,\ldots,\xi_n)$ или функцией совместного распределения случайных величин $\xi_1,\ldots,\xi_n$.

### Свойства функции совместного распределения

Для простоты обозначений ограничимся вектором $(\xi_1,\xi_2)$ из двух величин.

- (F0) Для любых $x_1,\ x_2$ верно неравенство: $0 \le F_{\xi_1,\xi_2}(x_1,x_2) \le 1$.
- (F1) $F_{\xi_1,\xi_2}(x_1,x_2)$ не убывает по каждой координате вектора $(x_1,x_2)$.
- (F2) Для любого $i = 1,2$ существует $\displaystyle\lim_{x_i\to-\infty} F_{\xi_1,\xi_2}(x_1,x_2) = 0$. Существует двойной предел
$$\lim_{x_1\to+\infty}\lim_{x_2\to+\infty} F_{\xi_1,\xi_2}(x_1,x_2) = 1.$$
- (F3) Функция $F_{\xi_1,\xi_2}(x_1,x_2)$ непрерывна по каждой координате вектора $(x_1,x_2)$.
- (F4) Чтобы по функции совместного распределения восстановить функции распределения $\xi_1$ и $\xi_2$ в отдельности, следует устремить мешающую переменную к $+\infty$:
$$\lim_{x_1\to+\infty} F_{\xi_1,\xi_2}(x_1,x_2) = F_{\xi_2}(x_2), \qquad \lim_{x_2\to+\infty} F_{\xi_1,\xi_2}(x_1,x_2) = F_{\xi_1}(x_1).$$

### Плотность распределения

Случайные величины $\xi_1,\xi_2$ имеют абсолютно непрерывное совместное распределение, если существует неотрицательная функция $f_{\xi_1,\xi_2}(x,y)$ такая, что для любого* множества $B \in \mathbb{R}^2$ имеет место равенство
$$\mathsf{P}\big((\xi_1,\xi_2) \in B\big) = \iint\limits_B f_{\xi_1,\xi_2}(x,y)\,dx\,dy.$$

\* достаточно хорошего (борелевского).

### Плотность распределения

Если случайные величины $\xi_1, \xi_2$ имеют абсолютно непрерывное совместное распределение, то для любых $x_1$, $x_2$ имеет место равенство

$$F_{\xi_1,\xi_2}(x_1,\,x_2) = \mathsf{P}(\xi_1 < x_1,\, \xi_2 < x_2) = \int\limits_{-\infty}^{x_1} \left( \int\limits_{-\infty}^{x_2} f_{\xi_1,\xi_2}(x,\,y)\,dy \right) dx.$$

Если совместное распределение абсолютно непрерывно, то по функции совместного распределения его плотность находится как смешанная частная производная:

$$f_{\xi_1,\xi_2}(x,\,y) = \frac{\partial^2}{\partial x\,\partial y}\, F_{\xi_1,\xi_2}(x,\,y).$$

Если случайные величины $\xi_1$ и $\xi_2$ имеют абсолютно непрерывное совместное распределение с плотностью $f_{\xi_1,\xi_2}(x,\,y)$, то $\xi_1$ и $\xi_2$ в отдельности также имеют абсолютно непрерывное распределение с плотностями:

$$f_{\xi_1}(x) = \int\limits_{-\infty}^{\infty} f_{\xi_1,\xi_2}(x,\,y)\,dy; \qquad f_{\xi_2}(y) = \int\limits_{-\infty}^{\infty} f_{\xi_1,\xi_2}(x,\,y)\,dx.$$

Для $n > 2$ плотности случайных величин $\xi_1, \dots, \xi_n$ по плотности их совместного распределения $f_{\xi_1,\dots,\xi_n}(x_1, \dots, x_n)$ находятся интегрированием функции $f$ по всем «лишним» координатам.

### Формула свертки

Пусть $\xi$ и $\eta$ — непрерывные независимые случайные величины, тогда плотность суммы $\xi + \eta$ может быть найдена по формуле

$$f_{\xi+\eta}(x) = \int\limits_{-\infty}^{+\infty} f_\xi(t)\, f_\eta(x - t)\,dt.$$
